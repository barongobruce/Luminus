# Luminus — Hero Page

A single-page, responsive agency hero built with React, Vite, and TypeScript. It uses Comic Neue, a marshmallow-white / black / blaze-orange palette, the exact line “Bringing Brands into the light.”, two hero calls to action, a rounded-pill navbar, a persistent light/dark mode switch, three asymmetrical division cards, and a reusable pulsing loader.

## Run it locally

Requirements: Node.js 20.19+ (Node 22 recommended) and pnpm 11.25.0.
